# R042c Confirmatory Plan: Fair Validation-Gate Control

## Why this run exists

R042b remains a pre-registered FAIL because gated refinement (median unseen-test NMSE improvement 5.69%, 96.43% block wins) was below the all-calibration ungated control (6.94%, 94.64% wins). The result nevertheless strongly supports discrete `T` refinement over fixed-`T` AGA.

Post-result audit identified a comparison asymmetry: R042b's ungated control used fit+validation for both discrete selection and continuous fitting, while gated refinement selected on fit/validation but returned `alpha,mu` estimated only on fit. R042c corrects that asymmetry without changing the search budget, data, seed, blocks, or R042b verdict.

## Matched variants

- `fixed_t_allcal`: fixed initial `T`; fit `alpha,mu` on fit+validation.
- `ungated_fit_refit`: select `T` using fit only, then freeze `T` and refit only `alpha,mu` on fit+validation.
- `gated_refit`: propose `T` on fit and accept using validation, then freeze `T` and refit only `alpha,mu` on fit+validation.
- `ungated_allcal_refine`: uses fit+validation for `T` selection; retained only as an optimistic leakage/extra-data reference, not the gate comparator.
- `gated_no_refit`: reproduces the R042b handicap and quantifies the benefit of nuisance-parameter refitting.

All methods are evaluated on the same untouched three-sample test split. The test split remains unavailable to selection and refitting.

## Pre-registered R042c gate

Proceed to GPTQ integration only if `gated_refit`:

- improves median untouched-test NMSE over `fixed_t_allcal` by at least 2%;
- wins on at least 65% of blocks;
- has median improvement no lower than the capacity-matched `ungated_fit_refit` control.

The `ungated_allcal_refine` result cannot make the gate pass or fail. No rotation, SSR modification, new loss, larger search, or threshold tuning is allowed in R042c.

## Configuration

Identical to R042b: LLaMA-2-7B, layers 0/10/20/31, seven projections, two deterministic 128-column blocks per projection (56 total), WikiText2 seed 0, 12 sequences split 6/3/3, four coordinate proposals per row.
