# R045 Experiment Plan: Hierarchical Gate Discriminability

## Objective

Determine whether a higher-level held-out objective can identify and reject the layer-0 hard-`T` candidate that R044 proved harmful to WikiText2 PPL, despite its positive block NMSE and C4 effects. R045 does not search for a better candidate and does not run final PPL.

## Candidates

- `fixed_t_layer0`: official GPTQ/ATQ layer-0 quantization.
- `hard_t_layer0`: exact R044 validation-gated hard-`T` layer-0 quantization.
- FP16 layer output is the reconstruction reference; official fixed-`T` is the decision baseline.

Both candidates use identical source weights, GPTQ input state, calibration examples, group size 128, and seed. Candidate generation uses fit samples only; the scoring sequences are disjoint.

## Candidate scores

For complete held-out sequences, record:

1. transformer layer-0 output normalized MSE versus FP16;
2. layer-0 output cosine drift;
3. end-to-end mean token NLL after substituting the candidate layer into an otherwise identical model;
4. CVaR of the worst 10% token NLL increases relative to FP16;
5. maximum hidden-state RMS ratio and non-finite count.

No weighted sum is tuned in R045. Each metric is evaluated separately for discriminability.

## Pre-registered gate

R045 passes only if at least one predeclared higher-level metric ranks `fixed_t_layer0` above the known harmful `hard_t_layer0` candidate on every validation sequence, with no ties hidden by averaging. A metric that prefers hard-`T` cannot be used as the next acceptance rule, even if its mean difference is positive.

If layer-output metrics reject hard-`T`, adopt the simplest successful layer metric. If only token NLL/tail NLL rejects it, sequence-level validation is necessary. If no metric rejects it, the fit/validation distribution is insufficient; pivot to calibration-distribution design rather than tuning the hard-`T` search.

## Resource gate

The run should cache only layer-0 inputs/outputs and evaluate two candidates. No all-layer quantization, SSR, full PPL, or projection/layer sweep is authorized by this plan.
